🐛 R1 — Fix CONFIG Bug: NEUTRAL Wick Tolerance (Code Error) CRITICAL BUG

In the source code, NEUTRAL_WICK_TOLERANCE = 0.30 and TREND_WICK_TOLERANCE = 0.30 — both are identical. The code comment says "Max 15% wick allowed in neutral market" but the value is 0.30. Neutral markets should require stricter candle quality, not the same as trending markets.

# BUG — both same:
"NEUTRAL_WICK_TOLERANCE": 0.30, # comment says 15%!
"TREND_WICK_TOLERANCE": 0.30,

# FIX — tighten neutral:

"TREND_WICK_TOLERANCE": 0.35, # more lenient in strong trends
🐛 R2 — Fix CONFIG Bug: NEUTRAL Volume Multiplier (Code Error) CRITICAL BUG

The code comment on NEUTRAL_MIN_VOLUME_MULT says "Require 2.5x volume in neutral market" but the actual value is 1.5 — identical to MIN_VOLUME_MULT. Neutral/choppy markets should demand higher volume confirmation to filter out low-quality breakouts.

# BUG — comment says 2.5x, code says 1.5x:
"NEUTRAL_MIN_VOLUME_MULT": 1.5,

# FIX:
"NEUTRAL_MIN_VOLUME_MULT": 2.0, # stronger vol confirmation in chop
📉 R3 — BUY Signals Need Extra Confirmation Gate HIGH IMPACT

Over 15 days: BUY trades won only 24% of the time (7 wins / 29 trades, net -₹23,067). SELL trades won 73% (27/37, net +₹27,454). BUY signals are generating massive losses while SELL signals drive all the profit. This asymmetry is stark and cannot be ignored — March was a downtrend month.

Suggestions: (a) Add a second regime confirmation for BUY: require both NSE official A/D > 0.65 and the stock's sector must be green on the day. (b) Increase BREAKOUT_BUFFER for BUY signals only — this reduces false PDH breakouts. (c) For BUY signals, additionally require price > 20-period VWAP (currently VWAP check only rejects if below VWAP, which is already done — but could strengthen it).

⏰ R4 — Remove 09:30 Scan Slot (or Add Regime Stability Gate) HIGH IMPACT

The 09:30 scan is the largest single source of losses: 22 trades, 41% win rate, -₹15,237 net. At 09:30 the market regime is determined by NSE A/D data from 3 minutes earlier (09:27 last check). This data is often stale/transitional at open. On Mar 10, the bot took BUY entries at 09:30 — market turned BEARISH at 09:32. On Mar 6, same pattern.

Option A (Simple): Remove "09:30" from SCAN_TIMES — let the first scan be 09:45 after one candle of regime confirmation.
Option B (Smarter): Add a regime_stable_since timestamp. Only allow new entries if regime has been unchanged for ≥ 6 minutes (2 scheduler ticks).

🏛️ R6 — Expand Sector Filter from Top 5 → Top 7 MEDIUM IMPACT

The sector filter generated 775 rejections — the single largest rejection reason by far (more than all other filters combined). Top 5 out of ~20 tracked sectors means only 25% of sectors can produce setups on any given day. TataPower was rejected Mar 20 purely because NSE:NIFTYENERGY-INDEX was ranked #6 that day.

Expanding to Top 7 increases the candidate pool by ~40% while keeping the filter meaningful. For SELL signals specifically (where win rate is 73%), being slightly more permissive is statistically justified.

# Current (too restrictive):
top_secs = [format_sector_symbol(x[0]) for x in sorted_secs[:5]]

⚡ R7 — Add Regime Stability Gate Before New Entries MEDIUM IMPACT

The sentiment scheduler runs every 3 minutes. On volatile days (Mar 5, 6, 10, 12), regime shifted multiple times per hour. The scanner runs at fixed times and doesn't check if regime just changed. On Mar 10: BUY entries at 09:30, regime flipped BEARISH at 09:32 — 2 minutes later. The "regime_squeezed" flag then tightened SL 50%, but both trades still hit SL.

Add a global regime_stable_since timestamp. In run_scanner(), skip new BUY/SELL entries if regime changed within the last 6 minutes (2 checks).

# In run_sentiment_scheduler():
if market_regime != new_regime:
    regime_stable_since = time.time() # reset clock
    market_regime = new_regime

# In run_scanner(), add gate at top:
if (time.time() - regime_stable_since) < 360: # < 6 min

    return

🎯 R11 — ATR-Based SL Uses Stale ATR (Minor Improvement) MINOR

The SL is calculated as ATR * 1.5 using Wilder's 14-period ATR on 15-min candles from 7 days of history. The average SL distance observed was only 0.509%. For stocks priced ₹500–₹3000, this translates to ₹2.50–₹15 — extremely tight. On slow/consolidating stocks (HINDALCO, COLPAL), trades held 200–295 minutes before hitting this tiny SL.

Consider: SL = max(ATR * 1.5, price * 0.007) — a 0.7% minimum SL floor. This prevents extremely tight SLs on low-volatility stocks that lead to noise-exits followed by the position reversing in your favour.

# In run_scanner(), replace:
sl_distance = atr_value * 1.5

# With:
min_sl = last_candle['close'] * 0.007 # 0.7% floor
sl_distance = max(atr_value * 1.5, min_sl)
